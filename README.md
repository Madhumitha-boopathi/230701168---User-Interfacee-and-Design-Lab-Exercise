## 🧪 Overview

This repository contains the completed experiments and documentation for the **CS23A34 - User Interface Design Laboratory** course. The lab focuses on UI/UX concepts such as user recall, usability testing, task flows, layout prototyping, interface design, and data validation through hands-on tools and technologies.

---

## 🧰 Tools & Technologies Used

- **Figma, Proto.io, Wireflow, Lucidchart, Dia, Pencil Project, Inkscape, Balsamiq, OpenBoard**
- **HTML/CSS, JavaScript, Validator.js**
- **Python (Tkinter, SpeechRecognition, pyttsx3)**
- **Axure RP, OpenProj, GIMP, Chart.js**

---

## 📘 List of Experiments

1. UI Recall with Chunking – *Figma*  
2. CLI, GUI & VUI Comparison – *Python, Tkinter, Speech Recognition*  
3. Familiar vs. Unfamiliar Navigation – *Proto.io & Wireflow*  
4. Task Analysis & Wireframes – *Lucidchart & Dia*  
5. UI Lifecycle with RAD Model – *Axure RP & OpenProj*  
6. Layout & Color Scheme Testing – *GIMP*  
7. Paper to Digital Wireframes – *Pencil Project & Inkscape*  
8. Storyboarding a Mobile App – *Balsamiq & OpenBoard*  
9. Data Validation Forms – *HTML, CSS, JS*  
10. Data Visualization – *JavaScript & Chart.js*
